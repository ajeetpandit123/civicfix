# Add the pure media kind policy module

Create apps/api/src/services/mediaPolicy.ts with `MediaKind`, `ROLE_MEDIA_KINDS` (CITIZEN: EVIDENCE/REOPEN; FIELD_WORKER: BEFORE/AFTER/EVIDENCE/RESOLUTION; OFFICER: EVIDENCE/RESOLUTION; ADMIN: all five), `isMediaKindAllowed(role, kind): boolean` and `parseMediaKind(raw: unknown): MediaKind` (defaults undefined to 'EVIDENCE', throws ValidationError otherwise). No service/DB imports so it is trivially unit-testable.
